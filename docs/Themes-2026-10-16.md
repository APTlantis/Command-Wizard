# Theme maintenance verification — 2026-10-16

## Delivered

Eight built-in themes, a persistent header picker, a visible Customize theme entry point, and a local theme editor. Users can copy, name, edit OKLCH roles, preview, save, delete, export and import themes. Imports receive fresh IDs and require an explicit save. Built-ins are read-only. Navigation and app-close prompts protect unsaved drafts; failed saves retain them. Invalid persisted preferences are retained until an explicitly confirmed reset.

The [contract and recovery guide](Themes.md), [JSON Schema](../public/themes/theme.schema.json), portable examples, bundled theme data, exact source snapshots and role map are repository deliverables. The seven Desktop MD source token files still match the recorded SHA-256 hashes after this work. Their mapped OKLCH values are preserved exactly, and color-conversion tests recover their source hex values. Blue Slate's existing app palette remains the default. This does not revise City Hall standards or the theme resources in Desktop MD.

## Recovery and discovery

Select Blue Slate to restore the default appearance. Export custom themes for backup. Theme storage is a separate WebView `localStorage` preference, not command history. See the contract guide for corruption/reset and failed-write handling. Source refresh is an explicit developer script, never an app-start or build-time dependency on Desktop MD.

Direct project README, proposal, manifest and project readmap now link this feature. Drive/portfolio manifests and `D:\INDEX.md` do not need changes: project identity, physical paths, registration, authority and historical release posture are unchanged. No parent or canonical standard files were modified.
